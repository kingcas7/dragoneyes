☁️ 기기 간 동기화 (선택)

아래 3칸을 PC와 폰에 똑같이 입력하면 대화방과 대화 내역이 기기끼리 공유됩니다. 대화 내용은 동기화 암호로 암호화되어 저장됩니다.
API 키는 이 폰에만 저장되고 Anthropic 서버 외에는 어디에도 전송되지 않습니다. 대화 내용도 이 폰에만 저장됩니다. 사용한 만큼 API 요금이 부과되니 공용 기기에서는 사용 후 키를 지워주세요.

🧠 클로드 기억

필수 기억은 번호 순서대로 모든 대화에 항상 반영됩니다. 대화 중 "기억해줘, 나는 ..."라고 말해도 추가됩니다.
오래된 대화는 방마다 자동으로 요약 기억되어 유지됩니다.

💡 아이디어 메모

대화 중 "메모해줘, ..." 라고 말하면 여기에 즉시 저장됩니다 (API 비용 없음).
